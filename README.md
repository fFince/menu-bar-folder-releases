# Menu Bar Folder releases

Installers for [Menu Bar Folder](https://www.bessta.com/work/menu-bar-folder): put your menu bar items in folders. Hold ⌘ and drag an item onto a folder in the menu bar; click the folder to see what is inside.

Download the newest version from [bessta.com](https://www.bessta.com/work/menu-bar-folder) or from [Releases](https://github.com/fFince/menu-bar-folder-releases/releases/latest). Menu Bar Folder checks this page for updates and installs them itself.

- **Mac:** `MenuBarFolder.dmg` (macOS 27 or later, Apple silicon)

Menu Bar Folder is free.
